轮流学 · 知到双账号版使用说明
版本：1.5.2（免激活版）

首次使用，按下面的顺序操作即可。
打开即可使用，最多保存 2 个账号，同时最多运行 2 个账号。
无需激活码、邀请码、API 密钥，也不用安装 Python、Node 或 Docker。

1.5.1 故障恢复：获取课程遇到临时网络或服务异常时，会自动额外重试最多 2 次。
网络超时不再误提示为登录过期；只有明确的登录失效才要求重新登录。
持续失败会保留原有账号、课程列表和选择。重试情况显示在运行记录，诊断记录在 data-multi/service.log。

1.5.2 登录恢复：优先复用已保存的登录状态；旧接口会话失效时自动尝试恢复或官方续期，并加密保存新状态。主登录票据真正失效或平台要求验证时，仍需本人在官方页面处理。

一、从 QQ 群下载
1. 在 Windows 电脑上打开 QQ，进入群聊，打开“群文件”。
2. 找到“轮流学-双账号免激活版-Windows.zip”，点击下载，等待完整下载结束。
3. 点击“打开文件夹/打开所在文件夹”，找到下载的 ZIP 压缩包。
   请使用电脑下载和运行；手机不能运行里面的 EXE 程序。

二、完整解压
1. 右键点击 ZIP，选择“全部解压缩”（也可用电脑已有的解压软件）。
2. 选择固定、可写的文件夹，例如“文档\轮流学”，点击“提取/解压”。
3. 打开解压后的 ZhidaoMulti 文件夹，找到 ZhidaoMulti.exe。
   同一文件夹还应有 _internal、使用说明和来源说明等文件。

不要直接在压缩包预览窗口内运行 EXE，不要只把 EXE 单独拖出来。
必须保留整个 _internal 文件夹，程序才能正常启动。

三、启动程序
1. 需要 64 位 Windows、已安装的 Microsoft Edge，以及能正常连接知到的网络。
2. 双击 ZhidaoMulti.exe，稍等片刻，浏览器会自动打开管理页。
3. 默认地址：http://127.0.0.1:18665/
   这是你自己电脑上的管理页。把这个网址发给别人，别人不能访问你的程序。
   其他人需要自行下载、解压、运行。
4. 本版直接显示“把课程安排好”。如果看到激活码页面，说明打开的是旧版。

四、添加账号并登录
1. 点左侧“＋ 添加账号”，填一个备注，例如“我的账号”，再点“保存账号”。
2. 选中这个账号，点“账号密码登录”。
3. 程序会打开独立的 Edge 窗口，进入知到官方登录页。
4. 在官方页面选择密码登录，手动输入你原来就在用的知到账号和密码。
   协议、验证码及其他验证需要本人手动完成。
5. 登录成功后，程序读取课程，登录窗口关闭，管理页显示这个账号的课程。
6. 找不到窗口时，点登录对话框中的“显示登录窗口”。
   已在官方页面登录但尚未显示课程时，可以点“检查登录状态”。

管理页只保存备注，不接收或自动填写密码；登录后保存的是本机登录状态。
正常重启会保留登录状态，旧接口会话失效时会自动尝试恢复；主登录票据真正失效、退出登录或要求验证后，仍需重新登录。
程序使用专用 Edge 资料目录，平时的普通 Edge 已登录，不代表本程序已登录。
也可以点“扫码登录”，用知到 App 扫描，并在手机上确认。

五、第二个账号和课程选择
1. 按上面的方法再添加并登录第二个账号。最多保存 2 个账号。
2. 顶部“查看账号”选择谁，下面就显示谁的课程；左侧点击账号也可切换查看。
3. 分别给每个账号勾选要运行的课程，课程选择会自动保存。
4. 左侧账号旁的复选框，决定该账号是否参与“开始执行”。
   切换“查看账号”只切换课程显示，不会替你勾选参与执行的账号。
5. 账号旁的 ↑ ↓ 可以调整轮流执行顺序。
6. 不再使用某个账号时，点它旁边的“删除”，确认后可以添加其他账号。
   删除会清除该条账号的本机登录资料、课程列表和选择，不会删除知到平台账号。
   运行或登录过程中，需要先结束当前任务才能删除。

六、手动开始和两个账号同时运行
1. 在“启动与执行”里，把“课程启动方式”选成“手动开始”。
2. “账号执行方式”可选：
   · 按顺序轮流：先执行第一个账号的所选课程，再执行下一个账号。
   · 多账号同时执行：同时运行账号数设为 2，可以让两个账号一起执行。
     同一个账号内部的多门课程，仍按顺序执行。
3. 点“保存运行设置”。
4. 点“开始执行”：运行左侧已勾选账号各自选中的课程。
   点“只启动当前账号”：只运行当前查看账号的所选课程，即使左侧未勾选它也可以。
5. 点“暂停”后可点“继续”；点“停止”后等待当前任务停止完成。
   调整账号、课程或运行设置前，请先停止当前队列。

“每门运行上限”按单门课程本次运行计时，0 表示不设时间上限。
达到上限会转到后面的课程，显示“已达上限”，不代表课程完成。

七、每天定时和开机自启动
1. 把“课程启动方式”改为“每日定时”，选择每天开始时间，按北京时间计算。
2. 检查左侧参与执行的账号和各账号勾选的课程，点“保存运行设置”。
3. 页面会显示下一次执行时间。定时模式下也可以立即手动执行一轮。
4. 如需登录 Windows 后自动打开后台程序，可勾选“开机自启动”。
   此开关立即生效，不必再点保存；它只启动后台，不弹管理页或 Edge 登录窗口。
   是否自动执行课程，仍由“每日定时”设置决定。

定时需要电脑开机、联网，且程序保持运行。关机或睡眠时不会运行，也不会自动唤醒。
只关闭管理网页，后台仍继续；点页面左下角“退出程序”才会结束后台和定时。
再次双击 EXE 可以重新打开管理页，不必重复添加账号。
首次设置或修改时间，从下一次该时刻开始；停机错过已安排时间，重启后会补一轮。
已有队列运行时不重复开一轮，也不会把多天错过的任务全部堆积执行。
移动整个程序文件夹后，请重新关闭再开启一次“开机自启动”，更新启动路径。

八、怎么看是否正常运行
在“轮流执行/多账号同时执行”下方查看：
· 本轮整体进度：本轮各门课程进度的平均值，以及完成的课程数量。
· 课程总体进度：每门课程已完成视频的比例，首次读取前可能显示“待获取”。
· 运行记录：当前步骤、登录失效和其他错误提示。

进度按视频完成情况更新，不是每秒匀速增长。选课后还要点击开始，才会执行本轮。
最终学时和课程完成情况，请到知到官方页面核对。
目前主要适配知到共享课程，其他课程类型是否支持，以实际读取结果为准。
“自动处理视频弹题”沿用适配器能力，不包含章节考试代答功能。

九、常见问题
1. 网页没出现：稍等后再次双击 EXE，或在浏览器输入上面的本机地址。
   地址打不开时确认后台是否已退出；仍无法启动，可查看 data-multi/service.log。
2. 提示缺文件/DLL：确认完整解压，_internal 在 EXE 旁；重新下载并完整解压原压缩包。
3. Edge 窗口没出现：确认已安装 Microsoft Edge，再点“显示登录窗口”。
4. 提示获取课程失败：先按运行记录中的提示处理网络或平台故障；程序会自动尝试恢复失效的接口会话。
   自动恢复后仍提示登录失效或需要验证时，选中对应账号，在官方窗口重新登录并完成验证。
5. 开始按钮不能点：先登录、获取课程、勾选课程，并勾选左侧参与执行的账号。
   只运行当前账号时，也可以用“只启动当前账号”。
6. 定时没运行：检查设置是否保存、电脑是否睡眠/关机、网络和登录状态，以及后台是否退出。
7. 已有两个账号不能添加：这是本版固定上限，删除一个不再使用的账号后可换用其他账号。

十、数据、更新和分享
首次运行会在 EXE 旁生成 data-multi，保存登录状态、课程选择和设置。
备份前先退出程序，再备份整个 data-multi；加密数据通常只能由原 Windows 用户读取。
升级前先退出旧版并备份数据，替换程序文件时保留原 data-multi，启动后核对账号和课程。

转发时分享群里的原始干净 ZIP，不要把自己运行后的 data-multi 打包发出。
每个人在自己的电脑下载、解压并登录自己的账号，无需连接 AI 或第三方 API。
管理页只在本机访问，登录和课程功能需要联网访问知到平台。
